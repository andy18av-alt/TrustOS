# Mock Investigation Dataset

This folder contains the synthetic investigation dataset used to demonstrate the TrustOS end-to-end workflow.

## Purpose

- Populate the Analyst Work Queue
- Simulate realistic Trust & Safety investigations
- Demonstrate AI-powered risk assessment and decisioning
- Validate investigation, policy, and audit workflows

## Dataset Characteristics

- Entirely synthetic (no real customer, seller, or marketplace data)
- Covers multiple marketplaces and fraud scenarios
- Includes varying risk categories, priorities, and confidence levels
- Intended solely for demonstration, testing, and evaluation purposes

> **Note:** This dataset is provided to help reviewers understand and reproduce the TrustOS workflow. It does not contain any confidential or production data.
